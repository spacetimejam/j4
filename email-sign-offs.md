# Email sign-offs

The kit's shared sign-off bank. Every project reads this one file: there are no per-project copies and no per-project lists.

Emails sent from a project are signed off with one of these, chosen at random, with **no name after it**. Never sign with a name. Where the send supports an HTML body, the sign-off goes in **italics** (`<p><em>...</em></p>`). If the phrase might not read immediately as an obvious sign-off, append ` xo` after it, inside the italics. Pick one per email:

```bash
# $KIT is the kit checkout; your project spine file has the resolved path
grep '^- ' "$KIT/email-sign-offs.md" | sed 's/^- //' | shuf -n1
```

Adding an entry: it must work as a goodbye with nothing after it, so either a valediction shape (Yours in..., Warmest..., Regards...), a departure (off to, retreating, logging off), or a closing declaration. Each one is a statement of farewell; the dryness lands on the sender or the situation, never on the reader.
