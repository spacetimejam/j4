# Cover letter shape

Guidance for drafting `cover-letter.yaml` in each application folder.

- **Length:** most of a page, not more. Four or five paragraphs.
- **Order:** why-them before what-you-bring. Open with a specific, genuine reason this role or company is of interest, before turning to fit.
- **Evidence:** real projects and outcomes, drawn from `core/master-cv.md` and `core/stories.md`. No fabrication, no invented metrics.
- **Voice:** the user's own, per `core/voice.md`. Not the AI's default register.
- **Close:** direct and simple, no hard sell.

Treat every draft as a starting point for the user to shape, not a finished letter.
