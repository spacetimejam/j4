# Prompt: hiring-manager review

**When to use:** stage 4 of the case-study method, in a fresh session with no memory of the synthesis stage, once a case-study draft exists.

---

Read the attached case study as if you are a hiring manager in the user's field, seeing this project for the first time. You have not seen the interview answers or the raw material behind it, only the draft.

Give a straight assessment:

- What are the strengths of this case study, as written?
- What are the weaknesses? *Be specific: vague claims, unclear outcomes, pacing that loses the reader, anything that reads as generic rather than particular to this project.*
- Is it compelling? Would it make you want to shortlist this person?
- If you were interviewing them off the back of this, what would you ask?

Feed the answers back into a revision of the draft. Keep the accuracy rule in force: any change must still be grounded in the user's actual material, nothing invented to patch a weak spot.
