# Prompt: question generator

**When to use:** stage 2 of the case-study method, after the generic interview questions have been answered for a project, before synthesis. Paste this prompt to the AI in a session with this project's material to hand.

---

You are helping prepare for a portfolio case study. Read `portfolio/site.md` for this project's entry (URL, what the images show, current copy state) and any existing copy for the project that's available.

Produce a short list of extra questions specific to this project, beyond the generic set in `case-studies/interview-questions.md`. Look for:

- Anything on the live site that's flagged as placeholder, outdated or mismatched copy, and ask what it should actually say.
- Gaps between what the images show and what the existing copy describes.
- Anything unusual about this project that the generic questions wouldn't surface, an unusual client relationship, a second phase of work, a constraint specific to the sector.

Keep the list short, five questions or fewer. Don't repeat ground the generic question set already covers.
