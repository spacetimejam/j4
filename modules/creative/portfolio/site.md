# Portfolio site map

The AI working on this job search cannot reliably browse an image-heavy portfolio site: it can fetch a page's HTML but not see what the images actually show. This file is the map, kept up to date by hand: a page per project, its URL, what the images show, and the current state of the copy on that page. When tailoring a CV, a cover letter or a case study, the AI reads this file instead of trying to browse the live site.

## How to fill this

Populate during onboarding or at the start of a case-study session (see `case-studies/README.md`). For each project on the site, add an entry:

```
### Project name
- URL: 
- Images: (what they show, in enough detail that someone who can't see them understands the work, e.g. "packaging range, six SKUs, shelf shot and close-up of print finish")
- Copy state: (live and current / placeholder / outdated / missing)
```

Keep entries short. The goal is enough context for the AI to write about the work accurately, not a full transcription of the site.
